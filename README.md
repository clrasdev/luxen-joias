# Luxen Joias e Acessórios

Site institucional e catálogo da **Luxen Joias e Acessórios**, desenvolvido em equipe utilizando **HTML, CSS e JavaScript** como trabalho da disciplina de **Web Coding**, do 2º período, no **Centro Universitário Maurício de Nassau (UNINASSAU)**.

## Sobre o Projeto

O projeto tem como objetivo apresentar a identidade da marca Luxen Joias e Acessórios por meio de um site institucional e catálogo digital, proporcionando aos visitantes uma experiência de navegação elegante, intuitiva e organizada.

A proposta é desenvolver uma plataforma que permita conhecer os produtos, explorar as coleções e acessar informações sobre a marca e seus canais de contato.

## Funcionalidades

- Página inicial com apresentação da marca.
- Catálogo de produtos com imagens, descrições e preços.
- Página de coleção.
- Carrinho de compras.
- Adição e remoção de produtos do carrinho.
- Alteração da quantidade de itens.
- Cálculo automático do subtotal e total.
- Página institucional com informações sobre a marca.
- Página de contato.

## Estrutura do Projeto

| Arquivo | Descrição |

| `paginas.css` | Estilos das páginas internas |

## Como Executar o Projeto

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html`.
4. Utilize a extensão **Live Server** para visualizar o site no navegador.
